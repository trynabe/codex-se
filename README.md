- Quiz 8 บท บทละ 20 ข้อ รวม 160 ข้อ: ข้อ 1–10 ง่าย ข้อ 11–15 ปานกลาง ข้อ 16–20 ยาก พร้อมเฉลย เหตุผล ป้ายระดับ และคะแนนแยกตามความยาก

- ฟอนต์ Anuphan ทั้งเว็บ รวมเมนู ปุ่ม ตาราง Quiz และแผนภาพ เก็บไฟล์ไว้ในเว็บ พร้อม SIL Open Font License
- ธีมขาว/ดำ สลับจากปุ่มมุมขวาบน จำค่าที่เลือกในเบราว์เซอร์

## เปิดในเครื่อง

เปิด `dist/index.html` ในเบราว์เซอร์ หรือเปิดเว็บไซต์จาก local HTTP server

เมื่อแตกไฟล์ ZIP แบบพกพา ให้เปิด `index.html` ซึ่งอยู่ระดับเดียวกับ CSS และ JavaScript
ห้ามแยกไฟล์ออกจากกัน เพราะหน้าตา เนื้อหาและฟอนต์อ้างอิงไฟล์ในโฟลเดอร์เดียวกัน

คะแนน Quiz อยู่ในรอบที่เปิดเว็บไซต์
ระดับความยากเป็นการจัดเพื่อทบทวนจากพื้นฐานไปการประยุกต์และวิเคราะห์ ไม่ใช่ระดับที่ผ่านการวัดทางสถิติจากผู้สอบจริง

## ขอบเขตและที่มา

ยึด Midterm Guideline หน้า 1 และภาพขอบเขตสอบที่ผู้ใช้แนบ
มีรายการเอกสารในหน้า “เอกสารที่ใช้อ่าน” และหมายเลขหน้าสไลด์ในบทเรียน
แนวคำตอบและ Quiz จัดทำเพื่อฝึก ไม่ใช่ข้อสอบจริงหรือเฉลยทางการ
ข้อกำหนดที่เติมสำหรับตัวอย่างระบุว่าเป็นข้อเสนอหรือสมมติฐาน
โจทย์ Lab สร้างจากแม่แบบในเบราว์เซอร์ โดยเรียบเรียงสถานการณ์ใหม่อิง UEBS, Studio และ PHTRS ในเอกสาร ไม่ใช่ข้อความโจทย์ต้นฉบับ ใช้กฎชุดเดียวกันสร้างโจทย์และแนวคำตอบ ไม่ต้องใช้บัญชีหรือบริการ API

เว็บไม่บรรจุ PDF/Word ต้นฉบับ ข้อมูลคำตอบไม่ถูกส่งออกจากเบราว์เซอร์

## ตรวจสอบแล้ว

ตรวจบทเรียน 8 บท ตัวอย่าง 6 ระบบและสามมุมมอง Quiz ทั้งตอบถูก/ผิดและคะแนน 15/15
ตรวจคลัง Quiz 160 ข้อ ทุกบทเรียงความยาก 10/5/5 มีตัวเลือกไม่ซ้ำและเฉลยครบ ทดสอบตอบครบทุกบทให้ได้ 20/20 คะแนนแยกระดับ และการตอบผิด/ทำซ้ำ
ตรวจ viewport มือถือ 390 px ไม่เกิด page overflow และเมนูใช้งานได้
ตรวจ Lab ฉบับย่อทั้ง 54 ชุดว่ามีข้อความต่างกัน บทบาทและความสัมพันธ์อ้างอิงได้ครบ ตรวจเฉลยทั้งสามแนว การซ่อน/เปิดและรีเซ็ตคำตอบเมื่อสุ่มใหม่ รวมถึงธีมดำและการอ่านบนมือถือ
